# ElectionLab Pro

Professional static election forecasting site with pages for Senate, House, governors, polling averages and individual races.

## Deploy update
Upload every file in this folder to the root of your existing GitHub repository. Allow GitHub to replace files with matching names, commit the changes, and Vercel will redeploy automatically.

## Important
Current race names and figures are demonstration data. Edit `data.js` to replace them with published ElectionLab data. The local admin page is a preview editor; secure cloud publishing will require the Supabase connection stage.
